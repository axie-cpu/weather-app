Atmosphere · Desktop Widget
===========================

A small always-on-top weather window that sits in a corner of your screen.

Requirements
------------
Node.js 18+ (https://nodejs.org)

Pin it
------
Windows:  double-click pin-atmosphere.bat
Mac/Linux:  ./pin-atmosphere.sh
  or in this folder:

    npm install
    npm run pin-atmosphere

The widget loads live weather from the Atmosphere site, stays above other
windows, and remembers its position. Use the tray icon or the title-bar
buttons to pin, snap to a corner, hide, or quit.

Corners: top-right (default), top-left, bottom-right, bottom-left.
Drag the title bar to move. Resize from the edges.
